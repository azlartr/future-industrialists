# صناعيو المستقبل

نسخة GitHub Pages من موقع التقارير، باللغة العربية.

- الموقع: https://azlartr.github.io/future-industrialists/
- الإدارة: https://azlartr.github.io/future-industrialists/admin.html
- النشر: Settings → Pages → Deploy from a branch → main → / (root).

## ربط لوحة التحكم

أنشئ Fine-grained personal access token لمستودع future-industrialists فقط بصلاحية Contents: Read and write. أدخله في لوحة التحكم؛ يُحفظ في sessionStorage لهذه الجلسة فقط. لا تُرسل المفتاح بالمحادثات أو تضعه في المستودع.

التقارير تحفظ في reports.json والصور الجديدة في assets/u/. تغييرات النشر قد تحتاج عدة دقائق. المستودع عام ويمكن قراءة بياناته وصوره.

## نقل أحدث التعديلات

من الموقع القديم اختر تصدير الإعدادات، ثم في الإدارة الجديدة اربط GitHub واضغط استيراد الإعدادات. النسخة المبدئية تحتوي آخر نسخة احتياطية محلية متاحة بتاريخ 2026-10-10 00:18 UTC، ولا تدّعي احتواء التعديلات الأحدث. الصور السابقة تحتفظ بروابطها الأصلية؛ لا تحذف الاستضافة القديمة قبل نقلها أو استبدالها.

تحليل نص الزيارات يعمل بمحلل محلي. جلب صور مجلدات Google Drive المشتركة يعمل من المتصفح: فعّل Google Drive API في مشروع Google Cloud، وأنشئ مفتاح API مقيّدًا بهذه الخدمة وبعنوان https://azlartr.github.io/*، ثم أدخله من تبويب «عام». شارك المجلد والصور مع «أي شخص لديه الرابط» بصلاحية العرض. المفتاح محفوظ في sessionStorage فقط. الصور المطابقة تُنسخ إلى assets/u/ على GitHub؛ لا تُحفظ روابط تحتوي المفتاح داخل التقارير. الصور غير المطابقة تبقى كما كانت، وأخطاء الوصول لا تمسح الصور الحالية. المجلدات الخاصة تحتاج مصادقة إضافية ولا يدعمها هذا الربط. لا تحفظ مفاتيح الخدمات ضمن الملفات العامة.
